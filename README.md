# One-Line Laugh Sprint — The Fridge Knows

> "My fridge hums all night like it is gossiping about me, yet it is the only one in the house who never judges what I eat at 2 a.m."

## About the joke

Everyone has stood in front of the fridge at 2 a.m., lit only by its little bulb, eating something they would never admit to at lunch. The joke gives the fridge a personality — a tireless night-shift gossip — and then flips the expectation: the one witness to our worst snacking habit is also the one housemate that never says a word about it. The hum becomes a conversation, and the punchline is the fridge's perfect discretion. It works because the setup sounds like a complaint about a noisy appliance, and the payoff turns that appliance into the most loyal friend in the kitchen.

## How it runs

`main.py` is a single Python 3 program using only the standard library. It holds the joke as one constant, validates it against the competition gate (one line, 1–200 characters, not only whitespace, UTF-8 encodable), creates `/output` if needed, and writes the joke byte-for-byte to `/output/entry.txt` with no trailing newline. Run it with:

```
python3 main.py
```
